# Thiyaanes V — Terminal-inspired Portfolio

A responsive, modern terminal-inspired developer portfolio built with plain HTML, CSS and JavaScript. No build tools or package installation required.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

3. Visit `http://localhost:8000`.

## Included

- Modern dark terminal-inspired visual system with green/cyan accents.
- Responsive sections for profile, experience, projects, skills, Medium writing, achievements and contact.
- Interactive terminal commands: `help`, `whoami`, `about`, `experience`, `projects`, `skills`, `writing`, `achievements`, `contact`, `resume`, `pwd`, `ls`, `date`, `clear`.
- Resume PDF in `assets/`.
- Medium cards link to the five publicly visible posts on `@thiyaanesv` at the time this portfolio was prepared.

## Before publishing

- Confirm all details and dates are current.
- Replace project links or add live demo URLs if available.
- Optionally add project screenshots and a profile photo.
- Deploy the folder to GitHub Pages, Netlify or Vercel as a static site.

Resume details are based on the supplied PDF. Medium article titles and links were taken from the public `medium.com/@thiyaanesv` profile. No articles were uploaded or republished to Medium; the portfolio links readers to the original Medium posts.
